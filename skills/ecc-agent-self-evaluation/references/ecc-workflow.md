# Codex 작업 절차

먼저 [원본 자료](ecc-upstream.md)에서 이 작업의 목표·입력·도메인별 판단 기준·산출물을 읽는다. 해당 기술 항목을 다음 Codex 실행 절차에 적용한다. 호스트 전용 도구와 자동 실행 지시는 현재 기능으로 가정하지 않는다.

1. 원본에서 관찰할 사용자 목표·합격/실패 조건·필요 자료를 추출한다.

2. 현재 Codex 실행 도구·입출력·권한을 확인한다. Claude CLI 출력 파서·모델 플래그를 Codex 실행기로 취급하지 않는다.

3. 실제 사용 사례와 경계·오류 사례를 준비한다. 독립 평가는 현재 위임·실행 권한에 따라 정답을 미리 주지 않고 수행한다.

4. 파일 구조 검사와 행동 평가를 구분한다. 실제 실행이 없으면 정적 검토만 보고한다.

5. 재현 가능한 실패에 한해 지침을 최소 수정하고 같은 목표를 다시 검증한다. 추가 실행기가 필요하면 의존성을 보고한다.
