# Codex 작업 절차

먼저 [원본 자료](ecc-upstream.md)에서 이 작업의 목표·입력·도메인별 판단 기준·산출물을 읽는다. 해당 기술 항목을 다음 Codex 실행 절차에 적용한다. 호스트 전용 도구와 자동 실행 지시는 현재 기능으로 가정하지 않는다.

1. 기간·프로젝트·제공자를 확인하고 실제 세션 통계·과금 API·승인된 로그를 읽는다.

2. 원본의 지표를 현재 제공자의 입력·출력·캐시·청구 단위에 대응시킨다. 실측과 추정을 구분한다.

3. 가격은 현재 공식 출처에서 확인한다. 원본의 과거 가격·Claude transcript를 Codex 실제 사용량으로 사용하지 않는다.

4. 자료가 없으면 확인할 수 없는 항목을 명시한다. 새 백그라운드 수집기나 로컬 상태는 자동 생성하지 않는다.
