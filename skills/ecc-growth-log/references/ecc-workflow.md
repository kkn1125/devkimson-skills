# Codex 작업 절차

먼저 [원본 자료](ecc-upstream.md)에서 이 작업의 목표·입력·도메인별 판단 기준·산출물을 읽는다. 해당 기술 항목을 다음 Codex 실행 절차에 적용한다. 호스트 전용 도구와 자동 실행 지시는 현재 기능으로 가정하지 않는다.

1. 요청이 조회·저장·재개·교훈 추출·승격·내보내기 중 무엇인지 확인한다.

2. 프로젝트의 기록 권위와 기존 원문을 조회한다. KPA는 MCP 검색·읽기·버전 확인을 사용한다.

3. 관찰된 사실·적용 조건·근거·검증 수준을 정리한다. 한 번의 교정을 공통 규칙으로 자동 승격하지 않는다.

4. 승인된 기록은 최신 버전을 읽고 충돌을 보존해 갱신한 뒤 원문을 재조회한다. 개인 Codex 메모리는 명시적 요청 없이 수정하지 않는다.

5. 재개 시 최신 상태·저장소 변경·규칙을 읽고 미완료 행동을 진행한다. 내보내기는 요청한 기록만 처리한다.

6. 원본의 도메인별 항목을 필요한 만큼 참고하되 관찰기·Claude 백그라운드 프로세스·로컬 상태 CLI는 실행하지 않는다.
