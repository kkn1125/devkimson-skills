# 출처와 취합 판단

검토일: 2026-10-13. 아래 공개 자료를 참고해 이 저장소의 지침과 예시를 재작성했다. 원본의 전면 금지 규칙과 정보 보존에 어긋나는 교정 예시는 가져오지 않았다. 외부 자료가 갱신되더라도 자동으로 규칙을 덮어쓰지 않는다.

## 참고 스킬

- Hardik Pandya, [stop-slop](https://github.com/hardikpandya/stop-slop): 불필요한 서두·반복·공허한 강조·습관적인 구조를 점검하는 원칙을 참고했다. 모든 부사·피동·사물 주어·세 항목 나열·줄표 금지와 35/50 점수에 따른 반복 교정은 채택하지 않았다.
- Lim Leesol, [stop-slop-ko](https://github.com/limleesol/stop-slop-ko): 한국어 표현과 문서 종류·말투 보존, 없는 사실을 추가하지 않는 원칙을 참고했다. 가능성 표현을 단정이나 약속으로 바꾸는 변환, 문단별 개수 제한, 원문에 없는 정보나 시제 변경을 포함한 예시는 채택하지 않았다.

두 프로젝트는 MIT이며 저작권·허가 고지는 이 스킬의 `LICENSE`에 보존한다. 이 취합판의 예시는 새로 작성했다.

## 한국어 규범 확인

- 국립국어원, [여겨집니다, 위치해 있습니다 비문인가요?](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=313646), 2025-04-24: `여겨지다`, `여겨지고 있습니다`, `위치해 있습니다`를 잘못된 표현으로 일괄 판정하지 않는다. 한국어판의 이중피동 목록을 그대로 가져오지 않은 근거다.
- 국립국어원, [무생물 주어 등 문의](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=308470), 2024-12-31: 무생물 주어와 능동·피동 표현을 허용하며 `-고 있다`를 틀린 표현으로 보지 않는다. 간결함에 관한 견해를 문법적 금지로 바꾸지 않는다.

이 답변은 해당 표현에 대한 근거다. 모든 사물 주어가 자연스럽다거나 피동을 항상 유지해야 한다는 일반 규칙은 아니다. 새 문법 판정이 필요하면 해당 맥락의 근거를 확인한다.

## 이 취합판에서 보완한 것

- 사실뿐 아니라 시제·부정·조건·범위·확실성·약속·인과관계를 보존한다.
- 근거 없는 주체·수치·사례·출처를 추가하지 않는다. 추상적인 핵심 주장을 지워 문제를 숨기지도 않는다.
- 수정은 국소적으로 수행하고, 최종 대조에서 실패하거나 판단이 어려우면 원문 표현을 유지한다.
- 코드·인용·기술 문자열, 혼합 언어와 실제 목록·절차를 보호한다.
- 교정해야 하는 사례와 그대로 두어야 하는 사례를 함께 검증한다. 점수나 길이만으로 품질을 평가하지 않는다.
