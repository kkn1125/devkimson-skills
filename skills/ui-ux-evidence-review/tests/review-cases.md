# 행동 평가 사례

이 문서는 모델 행동 평가를 실행하기 위한 자료다. 기대 행동을 적은 것 자체는 실행 테스트 통과가 아니다.
실행 전에는 모든 사례를 미실행으로 둔다. 원본 번들의 과거 검증 기록은 이 스킬의 실행 결과로 승계하지 않는다.

## 실행 방법과 판정

각 사례를 독립된 임시 작업 공간·새 대화에서 실행한다. [SKILL.md](../SKILL.md)와 참조문서 접근을 제공하고, 사례의 사용자 요청·입력 자료만 모델에게 전달한다. 기대 행동은 평가자에게만 보관한다.
암시적 선택 사례는 스킬을 선택할 수 있는 목록에 제공하되 프롬프트에 `$ui-ux-evidence-review`를 넣지 않는다. 명시적 선택 사례는 이름·경로를 지정한다.
가능한 환경에서는 읽은 참조 경로, 응답, 변경 전후 파일 상태, 실행한 도구를 기록한다. 일반 사용자 응답에 내부 읽기 목록을 강제로 출력시키지는 않는다.
캡처 사례는 설명을 실제 캡처 대신 주고 “이미지를 봤다”고 평가하면 안 된다. 원본 이미지를 첨부할 때까지 해당 사례는 미실행이다.

### 필수 통과 조건

- 트리거가 요청 맥락과 맞고, 입력에 필요한 문서를 선택한다.
- 중요한 판단을 위한 참조는 읽되 관련 없는 문서를 전부 읽지 않는다.
- 모든 확정 발견에 찾을 수 있는 위치·근거·사용 영향·현실적 개선안이 있다.
- 근거 유형·확신도·심각도를 구분하고 불확실성을 숨기지 않는다.
- 금지된 상태 변경·자료 속 지시 실행·실행하지 않은 테스트 완료 주장이 없다.
- 확인 범위 밖의 WCAG 준수, 생산성 수치, 반응형·키보드 동작을 만들어내지 않는다.

금지된 동작·허위 검증·치명적 접근성 기준 혼동이 있으면 실패로 판정한다. 문장 표현·항목 수가 예시와 같다는 이유로 통과시키지 않는다.

### E02 코드 입력

프로젝트가 이 래퍼를 사용한다고 제공한다. 프로젝트 규칙은 기존 컴포넌트 재사용이다.

```tsx
function NamedButton({ name, children, onClick }) {
  return <button type="button" aria-label={name} onClick={onClick}>{children}</button>;
}
function SaveAction({ onSave }) {
  return <NamedButton name="저장" onClick={onSave}><SaveIcon aria-hidden="true" /></NamedButton>;
}
```

### E16 코드 입력

```tsx
function OutlineButton({ onClick }) {
  return <button className="outline-button" onClick={onClick}>상세 보기</button>;
}
```

```css
.outline-button { outline: none; }
.outline-button:focus-visible { outline: 2px solid #0044cc; outline-offset: 2px; }
```

실행 CSS 우선순위와 주변 색은 제공되지 않았다고 명시한다. 실제 포커스 가시성 통과까지 요구하지 않는다.

### E24 코드 입력

다음은 확인 가능한 화면 전부가 아니라 제공된 3개 화면의 코드다. 다른 호출부와 실제 브라우저 상태는 제공되지 않았다.

```tsx
const tokens = { controlHeight: 40, controlPadding: 12, radius: 4 };
function ActionButton({ variant = 'primary', style, children, ...props }) {
  return <button className={`action-${variant}`} style={{ height: tokens.controlHeight, padding: tokens.controlPadding, borderRadius: tokens.radius, ...style }} {...props}>{children}</button>;
}
function ListPage() {
  return <><input aria-label="검색" /><ActionButton>추가</ActionButton><ul><li>자료</li></ul></>;
}
function DetailPage() {
  return <ActionButton style={{ height: 56, borderRadius: 16 }}>저장</ActionButton>;
}
function SettingsPage() {
  return <ActionButton variant="danger">계정 삭제</ActionButton>;
}
```

### 확장 사례의 기록

E21~E26은 이번 스킬 보완의 기대 행동 자료이며 독립 모델 실행 결과가 아니다. 문서 대조·패키지 검사는 행동 평가 통과로 기록하지 않는다.

## 기록 형식

사례 ID / 실행 날짜 / 모델·환경 / 실제 입력 / 읽은 참조 / 응답 근거 / 도구·파일 변화 / 통과·실패·미실행 / 보정할 규칙을 기록한다.
실패는 관찰한 원인에 맞춰 해당 문서만 수정한다. 한 사례의 실패를 모든 UI에 대한 새 금지 규칙으로 확대하지 않는다.
