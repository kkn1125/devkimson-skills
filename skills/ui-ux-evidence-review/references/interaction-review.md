# 모달·팝업·드롭다운 인터랙션 검토

## 대상을 먼저 모으고 범위를 표시한다

검토 대상 화면의 트리거 → 실제 열린 UI → 공용 래퍼/호출부를 연결해 모달·확인창·팝업·드롭다운·팝오버 목록을 만든다.
입력 방식·중첩 상태·수정/저장 중 상태가 판단을 바꾸면 별도로 기록한다. ‘전체 모달’ 요청은 접근 가능한 범위의 대상 전부를 목록화하고 발견 일부만 보고하지 않는다.
동적으로 생성되거나 권한/자료 때문에 확인하지 못한 대상은 미확인 목록에 둔다. 한 화면·몇 개 호출부만 보고 앱 전체를 점검했다고 말하지 않는다.
소스가 있으면 포커스 처리를 라이브러리·공용 래퍼까지 따라간다. 호출부에 autoFocus/keydown이 없다는 이유만으로 실제 누락을 단정하지 않는다.

## 패턴에 맞는 동작을 확인한다

| 항목 | 확인할 행동 |
| --- | --- |
| 열기와 초기 포커스 | 실제 활성 요소가 적절한 첫 입력, 선택 항목, 주 액션 또는 내용 시작으로 가는가. 긴 안내·파괴적 확인은 제목/내용이나 안전한 액션이 더 적절할 수 있으므로 첫 입력/주 액션을 무조건 강제하지 않는다. |
| 닫기와 복귀 | 닫기·취소·완료·Escape 뒤 트리거로 돌아가는가. 트리거가 제거되거나 다음 작업으로 넘어간 경우 논리적인 다음 요소로 복귀하는지 확인한다. |
| Escape | 해당 패턴에서 닫히는가. 중첩된 메뉴/팝업에서는 최상위부터 닫히고 아래 폼이나 입력을 함께 폐기하지 않는가. 닫기가 실행 취소와 같은지 별도 확인한다. |
| 포커스 범위 | 모달은 Tab/Shift+Tab이 내부에 유지되고 배경으로 새지 않는가. 비모달 팝오버·드롭다운·툴팁에 모달의 focus trap을 일괄 강제하지 않는다. 빠져나갈 수 없는 키보드 함정과 모달 내 포커스 유지는 구분한다. |
| 바깥 클릭 | 닫힘/유지/변경 폐기 확인이 제품 의도와 맞는가. 입력 변경이나 저장 중 상태를 잃는지 확인하고 무조건 닫기를 정답으로 삼지 않는다. |
| Tab과 포커스 표시 | 읽기/행동 순서와 포커스 순서가 맞고, 포커스가 보이며 스크롤/고정 footer 뒤에 가리지 않는가. 메뉴·셀렉트의 방향키/roving focus 등 실제 패턴도 확인한다. |
| Enter 제출 | 폼의 Enter가 의도한 제출을 한 번 실행하는가. textarea의 줄바꿈, 셀렉트/자동완성의 선택, 채팅의 Enter/Shift+Enter, 한글 조합 중 입력과 충돌하지 않는가. 실제 저장·발송은 허용된 fixture에서만 확인한다. |

열기 → 초기 포커스 → Tab/Shift+Tab → 선택/입력 → Escape/닫기/바깥 클릭 → 포커스 복귀를 실제로 확인하고, 필요한 경우 Enter 동작과 중첩 UI를 추가한다.
캡처만 있으면 초기 포커스·trap·복귀·Escape·Tab·Enter는 미확인이다. 코드 검토와 실제 키 입력 결과를 분리한다.
모달 이름·역할·aria-modal·배경 접근과 준수 판단에는 [접근성](accessibility.md)을 함께 확인한다. 이 문서는 키보드/스크린리더 실검증이나 WCAG 인증을 대신하지 않는다.

## 포커스 문제 모달을 전부 보고한다

검토 범위의 대상 목록과 확인 방식(실제 조작/코드 후보/미확인)을 먼저 표시한다.
초기·복귀 포커스가 누락되거나 부적절한 **모든** 모달을 다음 표에 기록한다. 요약의 1~3개 가이드 때문에 목록을 줄이지 않는다.

| 모달·위치/트리거 | 현재 포커스 문제 | 근거·확신도 | 개선 방향 |
| --- | --- | --- | --- |
| 실제 모달 이름·화면·열기 요소 | 초기/복귀/Tab/trap/닫기 중 확인한 문제와 기대/실제 동작 | 조작 조건·활성 요소 또는 연결된 코드/래퍼 | 최소 수정과 재확인 경로 |

Escape·바깥 클릭·Enter 등 다른 인터랙션 문제도 같은 대상에 묶거나 별도 발견으로 연결한다.
코드만으로 의심한 대상은 실제 누락 목록과 구분한다. 미확인 대상·상태와 가장 작은 후속 확인 방법을 따로 적는다.
문제가 없다면 ‘확인한 모달 범위에서 문제 미발견’으로 기록한다. 전체를 확인하지 않은 경우 ‘포커스 누락 없음’이라고 일반화하지 않는다.
