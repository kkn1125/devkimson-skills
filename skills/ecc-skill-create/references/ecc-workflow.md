# Codex 작업 절차

먼저 [원본 자료](ecc-upstream.md)에서 이 작업의 목표·입력·도메인별 판단 기준·산출물을 읽는다. 해당 기술 항목을 다음 Codex 실행 절차에 적용한다. 호스트 전용 도구와 자동 실행 지시는 현재 기능으로 가정하지 않는다.

1. 대상 제품·작업·실제 버전·설치 경로·현재 설정을 확인한다. 명령 이름으로 설치 여부를 추정하지 않는다.

2. Codex 기능은 현재 OpenAI 공식 문서와 도구로 확인한다. 다른 제품 자체를 다루는 작업은 그 제품의 공식 API와 이름을 유지한다.

3. 원본의 점검 항목에서 목표·입출력·판단 기준을 추출하고 제공되지 않은 런타임·권한·설정 키를 명시한다.

4. 일반 지침과 검증으로 가능한 부분을 수행한다. 훅을 요청받았다면 지원 이벤트·스키마·실행 환경·신뢰 검토를 확인해 최소 설정을 준비한다.

5. 프로젝트 권위를 보존하며 요청한 설정만 수정하고 원문·실제 동작을 확인한다. KPA의 원본 관리와 런타임 설치를 구분한다.

6. 이 스킬 묶음은 ECC 전체 플러그인·공유 런타임을 설치하지 않는다. 원본 셋업·업데이트·수집 명령은 자동 실행하지 않는다.
